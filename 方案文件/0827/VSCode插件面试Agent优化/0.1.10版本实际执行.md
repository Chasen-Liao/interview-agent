## 1. 执行范围

## 3. 实际改动

### 3.1 OCR 进度

相关文件：

| 文件 | 改动 |
|---|---|
| [resume_ocr.py](../../../agent/resume_ocr.py) | 增加 `on_progress` 回调；CLI 将 OCR 进度以 JSON Lines 写入 stderr，stdout 只输出最终文本 |
| [webviewPanel.ts](../../../vscode-extension/src/webviewPanel.ts) | `runResumeOcr` 改用 `spawn` 实时读取 stderr；解析 `ocr_progress` 后转发 Webview；非 JSON stderr 仍作为错误详情 |

| [test_resume_ocr.py](../../../agent/tests/test_resume_ocr.py) | 覆盖图片 OCR 进度和 stdout/stderr 分离 |
| [test_resume_ocr_integration.py](../../../agent/tests/test_resume_ocr_integration.py) | 真实 OCR 集成测试断言进度事件 |

## 4. 验证结果

已执行：

```powershell
cd D:\project\interview-agent
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check agent
$env:INTERVIEW_AGENT_RUN_OCR='1'; .\.venv\Scripts\python.exe -m pytest agent\tests -m ocr -s
```

结果：

| 命令 | 结果 |
|---|---|
| Python 全量测试 | 206 passed, 1 skipped |
| ruff | All checks passed |
| OCR 集成测试 | 1 passed, 206 deselected |
| 图片 OCR 耗时 | 3.19s |
| 扫描版 PDF OCR 耗时 | 3.33s |
| OCR CLI stdout/stderr 分离 | returncode=0；stdout 含 OCR 文本且不含 `ocr_progress`；stderr 含 `ocr_progress` |

已执行：

```powershell
cd D:\project\interview-agent\vscode-extension
npm test
npx tsc -p ./ --noEmit
npm run compile
npm run prepare-agent
npx vsce ls
npm run package
```

结果：

| 命令 | 结果 |
|---|---|
| `npm test` | 11 files passed, 86 tests passed |
| `npx tsc -p ./ --noEmit` | 通过 |
| `npm run compile` | 通过 |
| `npm run prepare-agent` | 通过 |

一次无效验证：

```powershell

```

结果：失败，原因是 Vitest 不支持 Jest 的 `--runInBand` 参数。随后已使用项目正确命令 `npm test` 重新验证通过。

## 5. 未覆盖风险

1. 未在真实安装后的 VS Code 界面中逐项手工验收，需要按最终验收步骤安装 0.1.10 VSIX 后确认。
2. `.vscodeignore` 排除了 `pdf.worker.js` 和未使用的 `pdf.js` 版本；当前自动测试验证了默认 PDF 文本解析，复杂 PDF 仍建议手工上传确认。
3. 框架迁移只完成设计评估，未做 LangChain / AutoGen / AgentScope PoC。
